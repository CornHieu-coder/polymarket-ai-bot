# Polymarket AI Bot Research

This repository is a research-first AI prediction-market project investigating:

1. AI probability forecasting;
2. proper-betting conversion of forecasting edge;
3. execution-aware simulation; and
4. later position-sizing and risk research.

The project is currently in its research and scaffolding stage. It does not contain a trading bot or live-trading system.
